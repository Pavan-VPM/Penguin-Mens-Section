# PYI Frontend - Pick Your Influencer
## Tech Stack

- **Vite** - Fast build tool
- **React 18** - UI library
- **Tailwind CSS** - Utility-first CSS framework
- **React Router** - Client-side routing
- **Axios** - HTTP client

## Setup

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
App runs at `http://localhost:5173/`

### Production Build
```bash
npm run build
npm run preview
```
